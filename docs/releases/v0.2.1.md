# Rustrace v0.2.1

## Quoted Run arguments

The console now supports single- and double-quoted program arguments after
`cargo run --`, including JSON and arguments containing spaces:

```console
cargo run -- https://example.com --json '{"name": "Alice", "role": "admin"}'
```

The JSON is passed as one argument with its double quotes intact. Single
quotes preserve their contents. Double quotes support escaped double quotes
and backslashes. No shell is invoked: variables, wildcards, and command
substitutions remain literal. Only unquoted `<` and `>` tokens redirect input
and output. Existing argument limits and command restrictions still apply.

## Compatibility

Quoted Run arguments use the existing recorded argument format. This change
requires no new event format or assignment-package migration.

The v0.2.0 targeted Test compatibility requirement still applies: staff must
use v0.2.0 or later compatible readers for recordings containing
`cargo test --test TARGET FILTER -- --exact`. A published update does not
establish that staff installations were updated. See the
[reader compatibility guidance](v0.2.0-reader-compatibility.md).

The student guide now explicitly distinguishes packaged cases from Cargo
integration tests in F4, including their different deadlines and results.
The Assignment 3 package already includes ten public integration tests and
two packaged help checks; it does not need repacking.

## Validation

Quoted arguments are covered through parsing, command preparation, a real
terminal interaction, journal recording, bundle creation, and verification.
Targeted Test recording/verification and the existing submission, retention,
and long-session suites are included in release validation.
